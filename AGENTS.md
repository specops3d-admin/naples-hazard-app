# Naples Hazards Application Rules

## Project purpose

Build an educational and project-management application for the
Naples, Italy Hazards Assessment group project.

## Technology

- Next.js App Router
- TypeScript
- Tailwind CSS
- React components
- Vercel deployment
- Responsive desktop and mobile design

## Source requirements

- Use only information supported by the PowerPoint and Excel files.
- Do not invent scientific facts, statistics, sources, or team assignments.
- Preserve source names, URLs, slide numbers, and planning estimates.
- Clearly identify classroom planning estimates as estimates.
- Keep generalized maps labeled as generalized.
- Do not modify the original PowerPoint or Excel files.

## Application requirements

- Create accessible navigation.
- Use reusable components.
- Add loading and error states where appropriate.
- Make all tables responsive.
- Use status badges and progress bars.
- Add search and filtering to the source tracker.
- Explain scientific terminology in plain language.
- Do not expose private files or credentials.

## Quality requirements

- Run npm run build before completing major changes.
- Fix TypeScript and ESLint errors.
- Avoid placeholder content unless clearly labeled.
- Keep the design appropriate for a city-council hazard presentation.
